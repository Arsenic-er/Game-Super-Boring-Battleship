# Super Boring Battleship Game

> Лёгкая одиночная 3D-игра о морских боях Второй мировой от **koko** с неторопливым управлением кораблём, наглядной баллистикой и модульной системой повреждений.

[Скачать последнюю версию для Windows в виде каталога (ZIP)](https://github.com/Arsenic-er/Game-Super-Boring-Battleship/releases/latest)

## Об игре

Командуйте эсминцами, лёгкими крейсерами и линкорами в десятиминутных боях против ИИ или в неограниченных по времени ходовых испытаниях. Управляйте кораблём и борьбой за живучесть, применяйте артиллерию, торпеды, глубинные бомбы и палубную авиацию. Проект рассчитан на обычные ПК и создан на TypeScript, Babylon.js, Vite и Electron.

Игра всё ещё находится на стадии прототипа. Графика, баланс, модели кораблей и прогрессия будут улучшаться.

## Текущие возможности

- Исторически близкие машинные команды, постепенная перекладка руля, потеря скорости в повороте и повреждения модулей.
- Видимые траектории снарядов, разброс, перезарядка, независимое наведение башен, пробитие HE/AP и повреждения отсеков.
- Секторы торпедной стрельбы, узкий/широкий веер, дистанция взведения, дальность, упреждение и повреждение аппарата.
- Дым, гидроакустика, пожары, затопление, ремонт силами экипажа, восстанавливаемые очки прочности и зональные столкновения.
- Не всеведущая оптика ИИ: потерянные контакты оставляют только постепенно исчезающую последнюю известную позицию.
- Самолёты под управлением ИИ; игрок отдаёт приказы рамочным выделением, перемещением, охраной, патрулированием, перехватом и атакой кораблей.
- Арсенал без платежей, склад, верфь, локальный профиль командира и исследование исторического оснащения.
- Интерфейс на 简体中文, 繁體中文, English, 日本語, Español, Deutsch и Русский.

## Основное управление

| Клавиша | Действие |
|---|---|
| `W` / `S` | Увеличить или уменьшить машинную команду |
| `A` / `D` | Руль влево / вправо |
| Мышь / колесо | Двигать камеру / менять дальность прицела |
| `R` / `Space` | Переключить прицел / открыть огонь выбранным оружием |
| `1` / `2` / `3` | Главный калибр / торпеды / морская авиация |
| `Q` | Сменить боеприпас или веер торпед |
| `E` / `F` / `G` | Дым / гидроакустика / глубинные бомбы |
| `H` | Удерживать для ремонта корпуса |
| `M` / `F3` / `Esc` | Тактическая карта / отладка / выход или пауза |

## Запуск в Windows

Скачайте последний ZIP для Windows x64 со страницы [Releases](https://github.com/Arsenic-er/Game-Super-Boring-Battleship/releases/latest), полностью распакуйте его в одну папку и запустите `Super Boring Battleship Game.exe`. Не перемещайте EXE отдельно от каталога `resources` и DLL-файлов. Установка не требуется. SmartScreen может предупредить о неподписанной независимой тестовой сборке.

## Сборка для разработки

Требуются Node.js 24.x и npm.

```bash
npm install
npm test
npm run build
npm run desktop:dist
npm run desktop:zip
```

`desktop:dist` создаёт каталог `release/win-unpacked`; `desktop:zip` создаёт ZIP для публикации со всем каталогом игры.
