# 舰船模型候选

## 首选：Low poly WW2 destroyer

- 来源：https://sketchfab.com/3d-models/low-poly-ww2-destroyer-2514094cc7ba415599e5ffea92395296
- 作者：PandasEdge / TheCoolEpicPanda
- 许可证：Creative Commons Attribution 4.0（CC BY 4.0）
- 规模：约 1,000 三角形、579 顶点
- 优点：极低面数，适合当前低配置目标，也方便作为 LOD 远景模型。
- 注意：发行游戏时必须保留作者、模型链接和许可证署名。

当前程序化船体仅为灰盒占位物。渲染节点与舰船状态、碰撞分区和伤害模块相互独立，因此可替换为 glTF/GLB 模型，而无需修改战斗模拟。导入前仍需检查下载包中的实际格式、材质、轴向、比例以及炮塔是否能拆分旋转。

## 暂不采用：Sims Class Destroyer

- 来源：https://sketchfab.com/3d-models/sims-class-destroyer-wwii-us-navy-488ec4168b244b78a081a6fdc824a528
- 许可证：CC BY 4.0
- 规模：约 140 万三角形、69.24 万顶点
- 结论：细节较丰富，但对当前浏览器低配置目标过重；除非经过大幅减面和纹理优化，否则不直接用于游戏。
