## Scope and evidence standard

The user requested existing online aircraft-motion solutions and a replacement
for the mechanical, planar group movement. See `../AIR_FLIGHT_MODEL.md` for primary
references, equations, integration boundaries and deliberate limitations. No
external library, source code, artwork or new binary asset was imported.

This release changes authoritative leader guidance and motion, physically gated
attacks, visible wingman motion, authorized LAN interpolation and the developer
formation observation camera. It does not make each plane a separate combat actor.

## Real rendering and issues found during QA

`scripts/qa/air-sortie-visual-regression.mjs` uses real menu/map/C-command inputs,
then the unchanged production loop. A declared initial fixture places the selected
group2.4km from a stationary target and disables unrelated AA. After resuming,
entity state is read-only. Output videos are continuous, not synthetic poses.

The first recording was invalid: the test switched to a developer observer before
the normal player loop consumed the queued command. That QA timing defect was
fixed; it was not treated as a successful flight or a production-game regression.

Subsequent recording detected full-wing overlap during dive pull-out. Wider
stable-side formations and three-second closest-approach navigation fixed it;
positions are still integrated, never pushed apart. The old torpedo formation also
crossed its leader during a turn; stable left/right station assignments fixed that.
