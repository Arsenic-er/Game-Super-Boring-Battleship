# 0.7.9 — Dock installation preview consistency

## Fix and compatibility boundary

Dock candidate placement previously used the first empty slot unconditionally,
while the quick-equip transaction replaced slot zero for a new equipment model.
The same component could therefore be previewed at one hardpoint and installed
at another. A shared, pure resolver now determines placement, button wording and
the actual transaction. Existing policy is preserved: append an already installed
model to the first empty slot; otherwise use slot zero. Full racks retain the
existing first-slot replacement behavior.

The button now disables when all owned copies are installed, and incompatible
categories do not display an installable candidate ghost. A comparison preview
can remain visible when inventory is exhausted, but it does not grant equipment
or mutate the save. No economy, combat balance, save schema or historical model
change is part of this release. Selecting an exact arbitrary slot remains future work.
