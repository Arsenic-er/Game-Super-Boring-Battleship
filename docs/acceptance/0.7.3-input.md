# 0.7.3 input fixes

Date: 2026-09-13. Base: d0dba77. Canonical worktree remains on GPU-273312.

## Changes

- Combat camera input now requires ownership of the browser's actual Pointer
  Lock. Removed the unlocked client-coordinate fallback that stopped working at
  the window boundary. A trusted battle-start/resume action requests capture;
  rejected or lost capture displays a compact, localized click-to-return button.
- Relative motion is reset on lock/focus transitions. Intentional map, pause,
  developer-panel and main-menu interactions release capture; stale asynchronous
  lock grants cannot trap an inactive UI. Focus return alone does not steal lock.
- Ordinary squadron and target selection stays rectangular. A patrol drag uses
  its endpoints as a diameter, with their midpoint as the circle center. Preview
  and submitted command share the same world geometry and 250–2000 metre limits,
  including zoomed/panned maps. Updated all seven patrol/recovery prompt locales.
- Selecting a command closes the C palette while retaining the command mode;
  it no longer obscures the patrol drawing area. Escape preserves issued orders.
- `npm test` explicitly targets the application `tests` directory; the standalone
  Node transport tests run with `node --test`, not inside Vitest.

## Verified before packaging

- TypeScript check passed. Application regression excluding balanceLab: 810 pass,
  five intentional skips. The final one-line palette close change and its added
  assertions passed the 33-case focused air/map suite again.
- Eight standalone binary transport tests passed.
- Eight pointer-controller behavior tests passed, including request rejection,
  stale grants, no unlocked mouse-look, UI release and blur/focus behavior.
- Nine actual Chromium pointer checks passed with zero page errors. Headless
  cross-page native focus testing is explicitly environment-skipped: both pages
  reported `hasFocus=true` and no blur event occurred. This is not proof of native
  OS Alt-Tab behavior; controller blur/focus behavior has separate unit coverage.
- Real game browser test passed rectangular selection of three squadrons,
  forward and reverse/zoomed patrol drawing, preview-versus-simulation equality
  for all three issued orders, and retention after closing the map. No runtime
  page errors. The QA global exists only in an intercepted Vite response and is
  not included in the release bundle.
- Browser CDP absolute moves can inject paired recenter events. The pointer test
  checks each trusted event's relative delta and resulting angle, not a misleading
  net angle after opposite moves cancel.

- The balance suite passed all eight tests on the final isolated retry; the
  long batch took 28.852 seconds under its unchanged 30-second limit. An earlier
  contention-sensitive run failed that threshold. No physics values, assertions
  or timeout were changed. Total application results: 818 pass, five skipped.
