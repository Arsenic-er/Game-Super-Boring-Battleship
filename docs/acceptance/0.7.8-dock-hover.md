# 0.7.8 — Recovery and dockyard hover outline

## Scope

Continues the approved 0.7.7 port design after restoring the exact retirement backup
on GPU-821560. External mounted components receive a restrained light-cyan outline
using the same nearest-surface ray result as the hover tooltip. Matching includes
category, equipment ID and slot index, so identical guns are not highlighted together.
Internal compartments remain tooltip-only; candidate previews do not become installed parts.

The helper preserves original mesh outline properties and restores them on hover exit,
orbit/zoom, document hide/blur, loadout changes and disposal. It adds no mesh/material
or full-screen glow pass. Width is .12 model metres after visual verification found
.035 too faint. This is not a hull rebuild, a new 3D harbor or a battle/balance change.
