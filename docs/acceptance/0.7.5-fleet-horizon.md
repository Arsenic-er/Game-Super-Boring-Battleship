# 0.7.5 — Training contacts, aircraft formation and horizon

## Scope and causes

Based on `e97d785` in the canonical GPU-273312 server worktree. The user clarified
that the missing test enemy was a map marker, not a missing 3D hull.

- Sea trials skips normal combat perception. Its tactical map nevertheless read
  that empty perception list, while the 3D policy correctly displayed the target.
  A map-only contact adapter now includes every living training enemy, including
  developer-added ships. Normal battle detection and AI knowledge are unchanged.
- Aircraft were separate meshes but shared instantaneous group yaw/bank. The new
  bounded, render-only history makes each aircraft follow its own delayed path,
  tangent heading, bank and vertical motion. Stable slots preserve actual counts;
  no minimum-one or fabricated extra aircraft is added. Reset/pause and 30/60 fps
  behavior are covered. Dive pitch now follows the actual +Z model nose direction.
- Investigation did not find a general launch-count reduction bug: the real
  support groups launch with 6/5/5 aircraft and the developer default is five.
  GPU inspection verifies distinct, visible body and propeller world transforms.
  Unlaunched groups remain absent from the airborne renderer by design.
- Sky previously skipped battlefield fog, while a low camera compressed distant
  water fog into a nearly one-pixel line. A sky-only angular horizon blend and
  water-only, camera-height fog interval share the weather fog colour. Upper sky,
  ship visibility, scene fog and underwater behavior remain unchanged. Sky sampling
  is trilinear and the dome has 24 segments; no extra full-screen pass was added.

No save schema, economy, balance, LAN protocol, control binding or external binary
asset changes. All seven README versions are synchronized; no new UI strings.
