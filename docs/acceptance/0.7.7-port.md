# 0.7.7 — Sunny port and dockyard interaction

## Scope

Approved sunny-port concept implemented in the real game: left navigation, prominent
departure action, real 3D selected ship, transparent fifteen-hull selector, and on-demand
equipment/loadout/captain/help drawers. Instructions no longer fill the initial screen.
All seven locales use real translations. Inventory, progression, ordered slots, saved
builds, solo preparation and the existing two-player LAN flow are preserved.

Hover identifies actual external meshes and internal compartments. Camera motion is
damped and interruptible; cached actual geometry fits the initial 3/4 view without
cropping masts. UI transitions are 120/220 ms; complete-model presentation fades in
over 350 ms after shader/texture readiness. Reduced-motion preferences are respected.

This UI release retains the game's current lightweight ship geometry. It does not
claim the illustrative mock's detailed ship is newly modeled or that the harbor
background is a simulated 3D map. See root `design-qa.md` and `PORT_UI_ASSETS.md`.
