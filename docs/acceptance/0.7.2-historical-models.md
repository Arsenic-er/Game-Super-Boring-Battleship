# 0.7.2 historical model acceptance

Date: 2026-09-12. Base: `6f1fbb2`.

## Scope

- Original lightweight historical-style models for five destroyers, five light
  cruisers and five battleships, plus F6F-3, A6M2, SBD-2, D3A1, TBF-1 and B5N2.
- Distinct external weapon families and internal dock-inspection machinery.
- Shared metric weapon placement/elevation/muzzle geometry; stable empty slots.
- Preserve save format, equipment ownership, damage/reload values, seven locales
  and Windows directory distribution. No paid/extracted commercial-game assets.

Historical references and explicit approximations:
`../historical-models-ships.md`,
`../historical-models-equipment.md`,
`../historical-models-aircraft.md`.

## Reproduction

Run on the server worktree with its existing dependencies:

```sh
npx vitest run --maxWorkers=1
node --test scripts/qa/release-delta.test.mjs
npm run build
npm run assets:ships:validate -- public/assets/ships
node scripts/inspect-historical-models.mjs --help
node scripts/smoke-first-voyage.mjs
npm run desktop:zip
node scripts/validate-release.mjs
```

Browser QA uses the server-local Playwright/Chromium runtime under `.qa`.
Its loopback preview is temporary and must stop in a finally block.
No persistent user preview endpoint is part of this release.

## Limits

These are approximate historical silhouettes with intentionally simplified small
fittings, not exact CAD reconstructions or complete year-specific refits. The
equipped model follows the player's actual saved components; a historical hull
does not silently grant a fully equipped historical weapons loadout. Aircraft
team presets are visual defaults, not nation-lock rules.

Tall auxiliary supports currently follow the existing gameplay hardpoints rather
than exact historical platform layouts. QF5.25 and SKC/28 secondary housings still
share similar faceted silhouettes. These remain artwork refinement items, not
claims of completed blueprint-level reconstruction.

Software-WebGL draw/triangle counts are not a gaming-GPU FPS benchmark. A real
two-PC/home-router LAN test remains necessary and is not replaced by loopback
tests or model-gallery success.

The Windows screenshot also exposes pre-existing mixed-language runtime HUD
labels after switching to English. The seven choices and updated dock labels
were verified, not a complete seven-language UI audit. Track the remaining
runtime labels in a later localization pass.
